§1 Privacy Policy

1.1 What this app is

ScienceLoading Uploader is a single-operator automation tool. It exists to let Jeremy Lindley, the person who researches, writes, and produces every ScienceLoading video, publish those videos directly to platforms including TikTok without repeating the same manual upload steps by hand each time. It is not distributed to, or used by, anyone other than its own operator.

1.2 Information we access

Through TikTok's Content Posting API, this app accesses only:

OAuth access token Account ID Basic profile fields Video publish status

These are scoped entirely to the @scienceloading TikTok account — the operator's own account. The app never requests, receives, or processes data belonging to any other TikTok user, viewer, or third party.

1.3 Information we do not collect

  • No viewer analytics, cookies, or tracking pixels of any kind
  • No data from anyone who watches, likes, or comments on the published videos
  • No advertising identifiers, no location data, no device fingerprinting
  • No email addresses or contact lists beyond the operator's own

1.4 How information is stored and used

The access token issued by TikTok is stored in a local, non-public configuration file on the operator's own computer. It is used solely to authenticate the two API calls this tool makes: creating a video upload, and publishing it. The token is never transmitted anywhere other than to TikTok's own API endpoints, and is never shared with any other service, person, or company.

In plain terms: this app is the software equivalent of the operator clicking "Upload" in the TikTok app themselves — it just does the clicking on their behalf, for their own content, on their own account.

1.5 Data retention and deletion

Locally stored tokens persist only until the operator revokes them (via TikTok's own account settings) or deletes the local configuration file. Deleting the file or revoking access immediately and completely ends this app's ability to act on the account — there is no separate copy of any credential kept anywhere else.

1.6 Changes to this policy

If this app's scope of data access ever changes, this page will be updated and the "Effective" date above revised accordingly.

The app is used exclusively to:

  1. Publish video content that the operator created or holds rights to
